# Python Exercises

This folder contains small Python practice exercises for learning and review.

## Goals

- Practice core Python syntax
- Improve problem-solving skills
- Build familiarity with common language features

## Suggested Topics

- Variables and data types
- Conditionals and loops
- Functions
- Lists, tuples, sets, and dictionaries
- File handling
- Modules and packages
- Error handling

## How to Use

1. Open an exercise file.
2. Read the prompt or task.
3. Write your solution in Python.
4. Run the script and test your result.

## Notes

- Keep solutions simple and readable.
- Add comments only when they help clarify intent.
- Revisit exercises periodically to track progress.
