# Prompt Engineering

This folder contains notes, examples, and best practices for prompt engineering — crafting effective prompts for large language models.

## Contents

- `examples/` — sample prompts and their variations
- `templates/` — reusable prompt templates for common tasks
- `notes.md` — tips, heuristics, and lessons learned

## Goals

- Improve prompt clarity and specificity
- Reduce ambiguity and undesired outputs
- Create reusable, modular prompt components

## Guidelines

1. Be explicit about the task and desired format.
2. Provide examples when possible (few-shot).
3. Specify constraints (length, style, tone).
4. Use step-by-step instructions for complex tasks.
5. Validate outputs and iterate on prompts.

## Getting Started

1. Browse `examples/` to see working prompts.
2. Use `templates/` to bootstrap new prompts.
3. Add experiments and results to `notes.md`.

## Contribution

Feel free to add examples, templates, or notes. Use clear commit messages and include expected input/output for new prompt examples.
