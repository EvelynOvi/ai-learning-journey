# Resources

This folder contains curated learning resources for the AI learning journey.

## Purpose

- Keep useful references, guides, and supporting material in one place
- Collect links and notes that help with the rest of the repository
- Provide a quick index for topics worth revisiting

## What to Include

- Reference articles and documentation
- Cheat sheets and quick guides
- Notes, templates, and supporting files
- External links that are especially useful for learning

## How to Use

1. Add new resources as you find them.
2. Keep each entry short and clearly labeled.
3. Group related material into subfolders if the list grows.
4. Update this README when the folder contents change.

## Notes

- Prefer practical resources that support hands-on learning.
- Remove stale or duplicate links when you spot them.
